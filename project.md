# Project: Deccan Heights

## Project Description
A website for Deccan Heights Real Estate Agency

## Tech Stack
- **Framework**: Next.js 16.0.6
- **Language**: JavaScript (ES Modules)

### Styling & UI

- **CSS Framework**: Tailwind CSS 4
- **Animations**: Motion (Framer Motion)

### Development Tools

- **Linting**: ESLint
- **Package Manager**: npm


## Colors

1. Primary Color

Gold / Sandstone

HEX: #C6A15B
RGB: 198, 161, 91
Usage:

Main brand accents

Buttons (primary CTA)

Highlighted text

Icons & section headings

This color carries the premium real-estate feel shown in the logo.

2. Secondary Color
Charcoal / Deep Gray

HEX: #3C3C3C
RGB: 60, 60, 60
Usage:

Nav bar

Secondary buttons

Body text (strong emphasis)

Footer background

Gives a strong, trustworthy visual foundation.

3. Tertiary / Accent Color
Soft Gray / Silver

HEX: #BDBDBD
RGB: 189, 189, 189
Usage:

Dividers, borders (as seen under “Homes & Resorts”)

Icons

Muted text

Card outlines

This supports clean, modern UI elements.

4. Background Colors
Light Background

HEX: #F8F8F8
Usage:

Main webpage background

Section backgrounds with subtle contrast

Pure White

HEX: #FFFFFF
Usage:

Hero sections

Product/Property cards

Forms

📘 Recommended Website Usage Structure
Navigation Bar

Background: #3C3C3C (charcoal)

Logo: use original

Menu text: white

Hover: gold #C6A15B

Hero Section

Background: white

Headline: charcoal

CTA Button: gold background, white text

Section Highlights

Use gold for headers/icons

Use soft gray dividers (#BDBDBD)

Cards & Property Listings

Card background: white

Title text: charcoal

Price / key highlights: gold

Borders/shadows: soft gray

Footer

Dark background: charcoal #3C3C3C

Text: soft gray or white

Accent links hover: gold
